# Code of Conduct

DealLedger follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, criticize work rather than
people, and keep discussion about the record. Brokers, buyers, sellers,
researchers and developers are all welcome here.

Report unacceptable behavior privately to the maintainer listed in
[GOVERNANCE.md](GOVERNANCE.md) via GitHub. Reports are handled
confidentially.
