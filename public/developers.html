DealLedger API

Free, read-only, public-domain (CC0) data on US businesses for sale, observed directly on broker websites. No key, no signup. JSON by default, CSV with format=csv, and an MCP server for AI assistants.

Version 1 · first generationEndpoints, field names and listing numbers under /api/v1 stay stable. Breaking changes will go to /api/v2, with v1 kept running.

Quick start

curl "https://dealledger.org/api/v1/listings?state=TX&type=laundromat&limit=5"
curl "https://dealledger.org/api/v1/listings/1157161293"
curl "https://dealledger.org/api/v1/price-changes?state=FL&min_pct=10"
curl "https://dealledger.org/api/v1/listings?state=TX&type=laundromat&format=csv" > tx-laundromats.csv

Endpoints

GET /api/v1/listings

Search the public listing index — the same set the site shows.

ParameterMeaning
stateCode (TX) or name (Texas)
typeBusiness type, e.g. laundromat. Full list at /api/v1/reference
qWords in the listing title
brokerBroker website domain, e.g. example-brokers.com
min_price, max_priceAsking price, USD
min_cash_flowReported cash flow, USD
min_age_daysObserved on the market at least this many days (dated evidence only)
relistedtrue for listings with a possible-relist signal
sortnewest (default), oldest, price_desc, price_asc, cash_flow_desc, age_desc
limit, offsetPaging. limit ≤ 100 for JSON, ≤ 5,000 for CSV
formatcsv for a spreadsheet-ready download

GET /api/v1/listings/{listing_number}

Everything DealLedger has observed about one listing: price, cash flow, observed age with its evidence and confidence, reviewed price changes, relist signal, status and the broker’s original page.

GET /api/v1/price-changes

Reviewed asking-price changes, newest first. Parameters: state, type, direction (down default, up, any), min_pct, since (YYYY-MM-DD), limit, offset, format.

GET /api/v1/reference

Valid state codes and business types.

Responses

Search endpoints return the full match count and a paging cursor. Keep requesting with offset=next_offset until it is null to get every match — results are never silently cut off.

{
  "api_version": "1.0",
  "results": [ ... ],
  "total": 65,
  "limit": 25,
  "offset": 0,
  "next_offset": 25,
  "source": "DealLedger (dealledger.org) — CC0 public record ...",
  "license": "CC0-1.0"
}

Errors use HTTP status codes and one shape:

{ "api_version": "1.0", "error": { "code": "unknown_state", "message": "Unknown state \"Texsa\". Use a code (\"TX\") or name (\"Texas\")." } }

How to read the data

  • Observed age is a minimum. It comes from DealLedger’s crawls of broker sites, not verified days on market. Each age carries its basis and confidence.
  • Price changes are windows. Both prices were observed on the broker’s own page; the change happened between changed_after and changed_on_or_before. The exact day is unknown.
  • Relist signals are heuristics. A possible_relist is a match on state, price and title, never confirmed.
  • “No longer listed” is not “sold.” It means the ad disappeared from the broker site.

For AI assistants (MCP)

Connect any MCP-capable assistant to https://dealledger.org/api/mcp. Tools: search_listings, get_listing_history, search_price_changes, check_relisting. They run the same queries as this API.

Machine-readable spec: /openapi.json.

Terms & privacy

The data is public domain (CC0). Attribution to DealLedger is appreciated, not required. Responses are cached for up to an hour; data refreshes daily. What we log about API and MCP calls is in our privacy policy. Please keep automated use reasonable; heavy or commercial use: info@dealledger.org.
